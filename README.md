# SiliconBench

SiliconBench is a PPA-aware benchmark for RTL design systems. It evaluates generated hardware designs through correctness gates, synthesis, timing, and power analysis using open-source EDA tools.

This repository contains the public benchmark code, tasks, harness, flows, results, paper artifacts, and static site. Coordination, tickets, private decisions, and human sign-off records live in the separate private vault.
